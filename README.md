# surf-lang
Welcome to Surf v0.1! Surf was designed as a hobby project and to make Java easier to write.

The syntax maps very clearly to Java 11+, and so learning it as a Java developer is easy.

# Usage
Let's say you have a program.surf, here is how to compile and run it:
```Shell
javac surf.java
java surf program.surf
javac program.java
java program
```
This also works for any .surf script, it just writes to a .java file based on the input file.

Additionally, it does not delete the outputted Java, so you can inspect it anytime.
